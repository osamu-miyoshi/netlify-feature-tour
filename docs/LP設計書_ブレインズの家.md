## 要素2 ── LPタイプの決定

**直販型LP（＝来場予約直結型）**

ただし率直に申し上げる論点が1つある。
3,760万〜4,380万円の住宅は、LP内で「購入契約」まで完結しない。動画の定義における直販型の「ゴール」を、この商材では **現地見学・来場予約** と定義する。ここが実質のクロージング地点であり、広告費の回収を測る指標になる。

- **主CV（直販型のゴール）＝ 来場予約・電話**
- **副CV（受け皿）＝ 資料請求**

副CVを主CVと同格に並べると、来場予約の熱量が資料請求に流れて主CVが減る。**視覚的な優先順位を明確に差をつける**（主CV＝塗りつぶしボタン／副CV＝枠線ボタン）。

### 獲得後の工程（型を決めたら必須の確認事項）
- [ ] 来場予約 → 誰が何時間以内に連絡するか。**24時間以内で運用できるか要確認**
- [ ] 資料請求 → 送る資料は存在するか。[要確認：資料PDFの有無]
- [ ] 資料請求者への追客（メール/LINEのステップ配信）は設計済みか [要確認]

## 要素3 ── 事前リサーチと戦略設計（3C）

### ① 顧客（Customer）── 最重要

**ペルソナ**：知多半島（半田・常滑・武豊・阿久比・東浦・知多）在住、30代前半〜40代前半の共働き夫婦。子ども0〜2人。現在は賃貸で家賃7〜9万円台。世帯年収500〜800万円。

**ターゲットのジョブ（＝本当に片付けたい用事）**

「安いから買う」「性能が高いから買う」人はいない。表層のフックの奥にあるジョブは：

1. **「毎月の固定費が上がり続ける不安を、これ以上増やしたくない」**
   家賃を払い続けるのは嫌。でも家を買うと光熱費＋ローンで今より生活が苦しくなるのが怖い。電気代は年々上がっている。
2. **「注文住宅を建てる時間も自信もない。でも"建売っぽい家"には住みたくない」**
   打ち合わせを何十回もやる余裕がない。かといって、どこかで見たような外観・内装は嫌。
3. **「災害が来ても、家族と生活が止まらない家に住みたい」**
   南海トラフ。停電。子どもがいる家庭は特に。
4. **「家具まで含めて"暮らしが完成した状態"で始めたい」**
   引っ越してから家具を買い揃える時間もセンスの自信もない。

→ **得たい成果＝「月々の支払いが読めて、災害に強く、センスの良い暮らしが、打ち合わせなしで手に入る」**

**不安（LP内で潰すべきもの）**
- 太陽光・蓄電池って結局元が取れるのか？ 壊れたら？ 保証は？
- 建売だから間取りや仕様は選べないのでは？
- 見学に行ったらしつこく営業されるのでは？ ← **CVポイント直前で必ず潰す**
- ローンが通るか分からない
- [要確認：営業現場で実際に一番多い質問トップ3]

### ② 競合（Competitor）

| 競合 | 強み | ブレインズから見た弱み |
|---|---|---|
| 大手パワービルダーの建売 | 価格が安い、棟数が多い | 太陽光・蓄電池は非搭載かオプション、内装が没個性、家具なし |
| 地場工務店の注文住宅 | 自由設計 | 打ち合わせ回数が多い、完成まで長い、総額が読めない |
| 賃貸に住み続ける | 初期費用ゼロ | 家賃も光熱費も一生払い続け、資産が残らない |

[要確認：知多半島の実際の競合社名と、各社のLPで何を訴求しているか。動画の教え通り、競合LPを実際に見て一覧化しておく]

### ③ 自社・商品（Company）

**確認済みの事実**（公開情報より）

- 株式会社チタコーポレーション、**1995年創業・30年以上**、半田市。知多半島の総合不動産会社
- 土地探し／注文住宅（イシンホーム半田店）／分譲住宅（ブレインズの家）／売却・買取／賃貸（アパマンショップ半田店）／管理／インテリア（ACTUSパートナーショップ BRAINS）を一社で提供
- ブレインズの家は、**ACTUSを扱うBRAINSが、イシンホームの高性能住宅にACTUSのインテリアを入れた**ところから始まったブランド
- **大容量太陽光発電（一般家庭の約2倍）＋テスラ製蓄電池が標準装備**
- **断熱樹脂サッシ＋Low-Eガラス**による高気密・高断熱
- **耐震工法×減震摩擦工法**：震度7相当の大地震に8回耐える
- 花粉・PM2.5をブロックし、消臭・除菌・抗アレルゲンを実現する空調設備
- **ACTUSの家具をプロのコーディネーターが室内にコーディネート**
- 価格帯：3,760万円〜4,380万円（中島Ⅲ / 花園Ⅲ / 東浦森岡 / 中島Ⅴ 等）
- 月々実質支払い 7.4〜7.5万円の訴求実績（ルームツアー動画より）
- **一般住宅は光熱費が月約2万円。一生払い続けると住宅ローン約900万円の借入に相当。
  ブレインズの家は、900万円安い住宅と同じ総支払額で手に入る**

### 差別化ポイント（LPの背骨。ここだけは絶対に外さない）

> **「同じ月々の支払いで、光熱費のかからない、家具まで完成した、災害に強い家に住める」**

「品質が高い」「丁寧」では一切刺さらない。**900万円という具体的な金額**と**項目別の比較表**で示す。

## 要素4 ── ファーストビュー（60%）とCVポイント（20%）

### ファーストビュー 3点セット

| 要素 | 内容（A案） |
|---|---|
| ヘッドライン | 毎月2万円の光熱費。<br>35年で、住宅ローン**900万円分**です。 |
| サブヘッド | 大容量の太陽光発電とテスラ製蓄電池を標準装備。だからブレインズの家は、**900万円安い家と同じ総支払額**で手に入ります。半田・知多・阿久比の新築分譲住宅。 |
| キービジュアル | ACTUSでコーディネートされたリビングの実写 [要差し替え] |

**FVで伝えきる2つ**
1. 得たい未来＝月々の支払いが読めて、光熱費に怯えない暮らし
2. 差別化＝太陽光＋テスラ蓄電池＋ACTUS家具が「標準装備」

### CVポイント（出口）の設計原則

出口の離脱＝一番熱い客を最後に逃すこと。以下を必ず守る。

1. **入力した先の未来を書く** ── 「24時間以内にご連絡」「見学は約60分」「その場での契約の話は一切しません」
2. **項目分岐を先頭に置く** ── いきなり氏名住所を求めない。「ご希望は？（来場予約／資料請求／まず相談）」から始めて、答えた勢いで名前を入れてもらう
3. **必須を最小限に** ── 氏名＋連絡先1つ。住所は不要
4. **不安を出口で潰す** ── 「しつこい営業はいたしません」を送信ボタンの真上に置く

## 要素6 ── 新PASONAの法則（煽らない）

旧型の「このままでは家賃を捨て続けることになります」式の恐怖訴求は使わない。
高額商材ほど、煽られた瞬間にブランドが毀損する。**共感と提案で動かす。**

| 記号 | 役割 | 本LPでの内容 |
|---|---|---|
| **P** Problem | 問題提起 | 「毎月の光熱費、この先ずっと同じ額だと思っていませんか？」— 事実を示すだけ。脅さない |
| **A** Affinity | 親近感・共感 | 「私たちも半田で30年、"家賃と光熱費の両方が不安"という声をずっと聞いてきました」— 同じ目線から寄り添う |
| **S** Solution | 解決策 | ブレインズの家 ＝ 太陽光＋蓄電池＋高断熱＋ACTUS家具が標準の分譲住宅 |
| **O** Offer | 提案・**メカニズム** | なぜ光熱費が下がるのかを構造で説明。①一般家庭の約2倍の太陽光 ②テスラ蓄電池で夜も自給 ③樹脂サッシ+Low-Eで逃がさない → だから900万円分の差になる |
| **N** Narrow down | 絞り込み | 分譲住宅は**同じ家が二つとない＝各棟1組限り**。土地も1区画。これが誠実な「今動く理由」。架空の締切は作らない |
| **A** Action | 行動 | 「30秒で来場予約」。所要時間と手順を明示し、心理的ハードルを下げる |

### ルール（動画の注意点をそのまま運用に落とす）

- **感覚より数字を優先する。** 「動画は無い方がいい」と思っていたら、有る方がCVRが高かった——という事例は実際にある

### 写真選定の基準（LPの成果に直結する順）

1. **FVは「暮らしが完成している」と一目で分かる1枚**。生活感のある小物、自然光、人が写っていれば尚可。
   引きの構図で部屋全体が入るもの。寄りのディテール写真はFVに向きません。
2. **太陽光・蓄電池の実物写真は必ず1枚**。「標準装備」という言葉だけでは信じてもらえません。
3. **ギャラリーは部位がばらけるように選ぶ**。似た構図のリビングを6枚並べても情報が増えません。

### 注意
- Webサイトには `jpg260821web` フォルダ（web用）を使ってください。`jpg260821print` は印刷用で、
  ファイルサイズが大きく表示速度を落とします。FVの表示速度は離脱率に直結します。
- 1枚あたり200〜400KB程度まで圧縮してから配置することを推奨します。
