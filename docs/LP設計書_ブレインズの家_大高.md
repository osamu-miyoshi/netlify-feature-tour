# ブレインズの家 大高 LP 設計書

> ブランドLP（`/brains-house/`）とは別に、**物件別LP**（`/brains-house/odaka/`）として制作。
> 7要素の骨組みは共通。ここには**大高だから変えた点**と、公開前に必ず埋める`［要確認］`を書く。

---

## なぜブランドLPを流用せず、別ページにしたか

**商圏が違うからです。**

ブランドLPは半田・知多・阿久比向けで、「創業30年・地元密着」を社会的証明の柱に据えています。
これは知多半島では強く効きますが、**名古屋市緑区の検討者にはほとんど響きません**。
緑区で家を探している人が最初に見るのは、会社の歴史ではなく次の4つです。

1. 名古屋市内か
2. 駅から何分か
3. 学区はどこか
4. いくらか

したがって大高LPでは、**立地を独立したセクションに引き上げ、FV内で「どこ・いくら」を即答**する構成に変えました。
ブランドLPには無い「立地」「区画ラインナップ」「物件概要」の3セクションがこれにあたります。

---

## 変えた点

| 項目 | ブランドLP（半田・知多） | 大高LP |
|---|---|---|
| ヘッドライン | 毎月2万円の光熱費。35年で、住宅ローン900万円分です。 | **名古屋市内で、予算を900万円ふやす。** |
| 訴求の起点 | 光熱費という固定費 | **名古屋市内の土地値と予算のギャップ** |
| FV | ヘッドライン＋サブヘッド＋CTA | ＋**物件ファクト4項目**（所在地・交通・価格・棟数）を追加 |
| 立地 | なし（エリア名のみ） | **独立セクション**。物件LPの主役 |
| ラインナップ | 物件カード（複数物件） | **区画カード**（A号地・B号地…） |
| 物件概要 | なし | **あり**（宅建業法上の表示事項） |
| フォーム名 | `brains-house-reserve` | `brains-odaka-reserve`（リードを分離して計測） |

### 変えなかった点

**900万円ロジックは共通の背骨**です。これは商圏に依存しません。
むしろ地価の高い名古屋市内でこそ「予算が足りない」という悩みと噛み合い、知多よりも強く効くと判断しました。

太陽光＋テスラ蓄電池＋高気密高断熱のメカニズム説明、比較表、新PASONAの順序、
CVポイントの設計（分岐を先頭・必須2項目・入力後の流れの明示）もそのまま引き継いでいます。

## 公開前に必ず埋める［要確認］

**不動産広告は景表法・宅建業法の対象です。数字を一つも憶測で入れていません。**
特に交通の所要時間・徒歩分数の誤表記は不当表示になります。

### 最優先（これが無いと公開できない）

- [ ] **宅地建物取引業免許番号**
- [ ] **所在地**（地番まで）
- [ ] **交通**：大高駅からの徒歩分数（80m＝1分で算出、端数切り上げ）
- [ ] **価格**（区画ごと）
- [ ] **土地面積・建物面積・間取り**（区画ごと）
- [ ] **総戸数**
- [ ] **取引態様**（売主／媒介）
- [ ] **完成時期・引渡時期**
- [ ] **電話番号・受付時間**

### 立地セクション

- [ ] 大高駅から名古屋駅までの乗車時間（**実際のダイヤで確認**。時間帯で変わる旨も併記）
- [ ] イオンモール大高までの距離・所要時間
- [ ] 小学校・中学校の名称と距離 ← 子育て世帯は価格の次にここを見ます
- [ ] 小児科・総合病院・区役所など

### 訴求の裏づけ

- [ ] **累計販売棟数** ← 社会的証明の強度が一番跳ね上がる
- [ ] 900万円の算出根拠（借入金利・返済年数・世帯人数・使用電力量）
- [ ] 月々支払い額の前提条件（借入額・金利・返済年数・ボーナス払いの有無）
- [ ] 太陽光・蓄電池の保証年数と範囲、メンテナンス費用の目安
- [ ] 実際にお住まいの方の光熱費実績（**あればFAQ最強の答えになります**）

## ABテスト（要素7）

`?v=b` でFVがB案に切り替わり、フォームの `variant` にどちらから来たかが入ります。

| 案 | ヘッドライン | 狙い |
|---|---|---|
| A | 名古屋市内で、予算を900万円ふやす。 | 予算の悩みに直接刺す。緑区で予算が足りない層 |
| B | 大高に、光熱費のかからない家ができました。 | 立地を先に出す。大高で探している層 |

**どちらが勝つかは商圏と広告の出し方で変わります。感覚で決めず、A/Bそれぞれ1,000流入を目安に数字で判断してください。**
