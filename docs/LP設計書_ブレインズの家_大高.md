## 前提の訂正

初回の設計時、「大高」を**名古屋市緑区大高**（JR大高駅・イオンモール大高）と想定して立地セクションを組んだ。
**誤りだった。** 正しくは以下のとおり。

| | 誤（初回の想定） | 正 |
|---|---|---|
| 所在地 | 名古屋市緑区大高町 | **愛知県半田市大高町2丁目25** |
| 最寄駅 | JR大高駅 | **JR武豊線「亀崎」駅 徒歩22分** |
| 物件の性格 | 分譲住宅（複数区画） | **モデルハウス1棟** |
| 価格帯 | 3,760〜4,380万円想定 | **6,160万円（税込）** |

数字をすべて`［要確認］`にしていたため、誤った情報が残ることはなかった。
立地セクションとヘッドラインは全面的に作り直した。

## この物件の性格

**分譲住宅のラインナップではなく、6,160万円の平屋モデルハウス1棟。**

- 土地 361.5㎡（**109.35坪**）／建物 128.77㎡（38.95坪）
- **平屋**（木造1階建）、中庭とウッドデッキ
- 3LDK＋WIC＋FCL＋土間収納＋中庭
- **駐車場8台**
- 太陽光 **16.8kW**（LONGI 480W）、ZEH・BELS、耐震等級3＋減震装置
- 2026年9月完成

ブレインズの家の主力価格帯（3,760〜4,380万円）とは**客層がまったく違う**。
賃貸から抜け出したい若い共働き夫婦ではなく、この規模を選べる層に向けて書いてある。
109坪・駐車場8台・平屋という組み合わせから、車を複数持つ世帯、二世帯検討、地元の事業主などが想定される。

## 訴求の背骨を差し替えた

ブランドLPの「光熱費 月2万円＝住宅ローン約900万円」は**抽象**。
この物件には**実額**がある。

| | 金額 |
|---|---|
| 住宅ローン | ＋155,759円 |
| 光熱費 | ＋10,000円 |
| 売電収入 | −40,300円 |
| 住宅ローン減税 | −16,000円 |
| **月々の合計** | **109,459円** |

試算条件：頭金0円／ボーナス払い0円／金利1%／返済期間40年

**6,160万円の平屋が、月々10万円台。** これ以上に強い数字はないので、FVのヘッドラインに据えた。
900万円ロジックは使っていない。この物件では実額のほうが圧倒的に強いため。

### ⚠️ 表示上の注意（重要）

**売電収入とローン減税を差し引いた「合計金額」だけを単独で見せてはいけない。**
実際の住宅ローン返済額は155,759円であり、109,459円は各種の差引き後の数字。
内訳を隠して合計だけを訴求すると、**優良誤認（景表法）に問われうる**。

そのため本LPでは、
1. 合計額と**同じ枠の中に内訳4項目を必ず表示**
2. 試算条件をその直下に配置
3. 「売電収入は変動し、減税額は所得等の条件で異なる」旨の注記を枠外に配置
4. FAQにも同じ説明を再掲

という構成にしてある。**この構造を崩さないこと。**

さらに、金利1%・返済期間40年という前提は、実勢よりも低め・長めの可能性がある。
広告として出す前に、社内で試算条件の妥当性を確認しておくことを勧める。

## 駅徒歩22分を隠していない

**JR亀崎駅 徒歩22分、名古屋駅まで60分。** 通勤利便で戦える立地ではない。

LPでは、これを隠さず書いている。理由は2つ。

1. **隠しても現地で必ず発覚する。** 期待して来場した人が失望するのは、最も無駄な来場。
2. **距離と引き換えに何を得たかが、この物件の価値そのもの。** 109坪の敷地と8台分の駐車場は、
   駅近ではこの価格で成立しない。

立地セクションは「駅から離れています。そのかわり──」という書き出しにしてある。
弱点を先に認めたほうが、そのあとの主張が信用される。

## ABテスト（要素7）

`?v=b` でFVがB案に切り替わり、フォームの `variant` にどちらから来たかが入る。

| 案 | ヘッドライン | 狙い |
|---|---|---|
| A | 6,160万円の平屋を、月々109,459円で。 | 実額で殴る。価格で諦めかけている層 |
| B | 109坪の敷地に、中庭のある平屋。 | 暮らし方で引く。広さと平屋に反応する層 |

高額商材なのでA案が強いとは限らない。6,000万円台を検討できる層は、
月々の額よりも「その暮らしができるか」で決める可能性がある。
**感覚で決めず、A/Bそれぞれ1,000流入を目安に数字で判断すること。**
